# Requirements & Scoring

## 1. Project Setup — 10 points

- [ ]  Create a GitHub repository — **5pts**
- [ ]  readable folder structure (`/assets`, `/css`, `/js`, etc.) — **5pts**

---

## 2. HTML Structure & DOM — 20 points

- [ ]  Semantic structure (header, nav, main, footer) — **5pts**
- [ ]  Use lists(ol, ul), images, links, headings — **5pts**
- [ ]  Minimum 3 sections (Home, About, Projects) — **10pts**

---

## 3. CSS Styling — 25 points

- [ ]  Use Flexbox or Grid — **5pts**
- [ ]  Consistent typography and color palette — **5pts**
- [ ]  External CSS file (no inline CSS) — **5pts**
- [ ]  Responsive layout with at least two breakpoints — **10pts**

---

## 4. JavaScript Interactivity — 20 points

Choose any two:

- [ ]  Mobile menu toggle — **5pts**
- [ ]  Theme switcher (light/dark) — **5pts**
- [ ]  Improvised animations or transitions — **10pts**

---

## 5. Git & GitHub — 15 points

- [ ]  5-10 meaningful commits — **5pts**
- [ ]  Clear commit messages — **5pts**
- [ ]  README with project description and screenshot — **5pts**

---

## 6. Deployment — 10 points

- [ ]  Deploy to Netlify or Vercel — **10pts**

---

# Experienced Challenge Tasks (Optional, Double Points)

These tasks are optional.

Students who complete them receive **2× points** for each item.

Beginners may attempt them for bonus, but they are not required to pass.

---

## 7. Astro Framework Integration — 20pts/40 for beginners

- [ ]  Convert the site into an Astro project — **10pts**
- [ ]  Use Astro components for layout/header/footer — **10pts**

---

## 8. Tailwind CSS — 20pts/40 for beginners

- [ ]  Replace CSS with Tailwind utility classes — **10pts**
- [ ]  Custom Tailwind config (colors, fonts) — **5pts**
- [ ]  One reusable UI component (card, navbar, button, etc.) — **5pts**

---

## 9. React Components inside Astro — 20pts/40 for beginners

Create any two:

- [ ]  Project cards grid with hover effects — **10pts**
- [ ]  Contact form with basic validation — **10pts**

---

## 10. Mid-Level JavaScript — 15pts/30 for beginners

- [ ]  Animation using JS and external libraries — **15pts**

---

## 11. Git Advanced — 10pts/20 for beginners

- [ ]  Use branches and pull requests — **10pts**

---

## 12. DevOps Advanced — 15pts/30 for beginners

- [ ]  Automatic deployment pipeline (GitHub → Vercel) — **10pts**
- [ ]  Use environment variables and .gitignore them (API keys, forms) — **5pts**
- Optional: host with nginx and own domain (still counts as bonus)
